**********How to run the "News/blog platform"  **********

1. Download the project zip file

2. Extract the file and copy "News/blog platform" folder

3.Paste inside root directory(for xampp xampp/htdocs,)

4.Open PHPMyAdmin (http://localhost/phpmyadmin)

5. Create a database with the name  "blog"

6. Import Database_name.sql file(given inside the zip package in SQL file folder)

7. Run the script http://localhost/newsbolg_platform/login.php
